# ============================================================
#  保守期限 登録ファイル
#
#  このシステムが使っているもののうち、いつか期限が来るものを
#  ここに書いておくと、期限の90日前から毎朝通知されます。
#
#  ★ 書き方（1行に1件、縦棒 | で区切る） ★
#      期限 | 名前 | どこで使っているか | 期限が来たらどうするか | 出典URL
#
#      2027-10-31 | Python 3.11 | update.yml | 3.12以降へ上げる | https://…
#
#  ・期限は YYYY-MM-DD で書きます
#  ・出典URLは省略できます
#  ・行頭に # を付けると、その行は無視されます（一時的に止めたいとき）
#  ・日付が分からないものは、期限の欄に「未確認」と書いてください。
#    毎回「日付を調べてください」と促されます。
#
#  ★ 通知のされ方 ★
#    期限の90日前になると、GitHub に Issue が作られてメールが届きます。
#    同じ内容のIssueが開いている間は、重ねて作られません。
#    片付いたら、この行を消すか # を付けて、Issueを閉じてください。
# ============================================================
