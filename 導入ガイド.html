同梱ファイルの説明

通常、中身を編集する必要はありません。

ファイル役割触る必要

実行時刻を変えたい場合

.github/workflows/update.yml の - cron: '0 22 * * *' を編集します。

UTC表記なので日本時間から9引いてください（例：日本時間12時 → 0 3 * * *）。

ご注意

本ツールは厚労省の公表データを整形して表示するものです。処方判断など正式な用途では、必ず厚労省の原本をご確認ください。

方法A：GitHubで毎日自動更新

GitHubという無料サービスに仕組みを置きます。GitHub側のコンピュータが毎朝7時に動くので、あなたのPCは電源が切れていても更新されます。

できあがるもの

https://あなたの名前.github.io/リポジトリ名/ というURL

これをスマホのホーム画面に入れておけば、常に最新版が見られます。

必要なもの

  • メールアドレス（GitHubの登録用）
  • パソコン（設定作業のときだけ。以後は不要）
  • Pythonのインストールは不要です

すべて完了しました。以降は毎朝7時に自動で更新されます。何もする必要はありません。

手順（全7ステップ）

タップで開きます。番号を押すと完了マークが付きます。

1
GitHubにアカウントを作る
▶

github.com/signup を開き、メールアドレスとパスワードを登録します。

無料プランで十分です。

2
置き場所（リポジトリ）を作る
▶
  1. ログイン後、画面右上の ＋ → New repository をタップ
  2. Repository name に好きな名前を入力（例：iyakuhin）
  3. Public を選択
  4. 緑の Create repository ボタンをタップ

Publicを選んでください。Privateだと無料でのページ公開ができません。

3
ファイルをアップロードする
▶
  1. 作成された画面の uploading an existing file をタップ
    見当たらない場合は Add file → Upload files
  2. ZIPを解凍した中身を画面にドラッグ＆ドロップ
    解凍してできたフォルダを開き、中のファイル全部を選んでドラッグしてください
  3. 下の緑の Commit changes ボタンをタップ

.github フォルダも必ず含めてください。これが自動実行の本体です。

見えない場合：
Windows … 表示 → 隠しファイル にチェック
Mac … command + shift + .（ピリオド）

4
自動実行の許可を出す
▶

Settings → Actions → General

  1. 上部メニューの Settings（歯車）をタップ
  2. 左メニュー下方の Actions → General
  3. 一番下までスクロールし、Workflow permissions で
    Read and write permissions を選択
  4. Save をタップ

ここを飛ばすと後でエラーになります。忘れやすい手順です。

5
ページ公開の設定をする
▶

Settings → Pages

  1. Settings の左メニューから Pages をタップ
  2. Source のプルダウンを GitHub Actions に変更
6
初回だけ手動で動かす
▶
  1. 上部メニューの Actions をタップ
  2. 左の「医薬品供給状況の自動更新」をタップ
  3. 右側の Run workflow → もう一度 Run workflow
  4. 1〜2分待つと緑のチェック ✅ が付きます

この初回実行をしないと、次のステップでURLが表示されません。

7
できたURLを確認する
▶

Settings → Pages

上部に Your site is live at https://... とURLが表示されます。

スマホでそのURLを開き、ホーム画面に追加してください。

うまくいかないとき

症状対処
赤い ❌ が付く❌をタップするとエラー内容が読めます。多くは手順4の権限設定漏れです
URLが出ない手順5をやり直し。手順6の実行が成功していないとURLは出ません
Run workflow が無い.github フォルダが未アップロードです。手順3をやり直してください

方法B：自分のパソコンで動かす

スマホからは見られません。

PC内にHTMLファイルができるだけです。PCで使う場合や、動作確認をしたい場合向けです。

必要なもの

  • Python 3.8以上（3.11以上を推奨）
  • インターネット接続
  • 定期実行するなら、その時刻にPCがついていること

お疲れさまでした。同じフォルダにHTMLができています。

手順（全6ステップ）

1
Pythonが入っているか確認
▶

Windows：スタートメニューで「cmd」と検索し、コマンドプロンプトを開く
Mac：「ターミナル」アプリを開く

次を入力しEnter：

python3 --version

Python 3.11.5 のようにバージョンが出ればOKです。

出なかった場合（command not found／「認識されていません」）

python.org/downloads からインストールしてください。

Windowsの注意：インストーラ最初の画面で Add Python to PATH に必ずチェックを入れてください。忘れると上のコマンドが通りません。また python3 ではなく python の場合があります。

2
必要なライブラリを入れる
▶
pip install pandas openpyxl

Windowsで通らない場合：

py -m pip install pandas openpyxl
3
フォルダへ移動する
▶

ZIPを解凍した場所へ移動します。cd の後ろはご自身のパスに置き換えてください。

cd ~/Downloads/自動更新システム

↑ Macの例

cd C:\Users\yourname\Downloads\自動更新システム

↑ Windowsの例

簡単な方法：cd と入力した後（半角スペースまで入れる）、フォルダをターミナルの窓にドラッグ＆ドロップするとパスが自動入力されます。

4
まず確認だけしてみる
▶
python3 fetch_update.py --check

これはダウンロードもファイル作成もしません。厚労省ページを見に行けるかだけを確認する安全なコマンドです。

成功すると、こう表示されます：

[07:00:01] 厚労省ページを確認中… [07:00:02] 掲載中: 医療用医薬品供給状況 （令和８年７月22日現在） [07:00:02] --check のため、 ダウンロードは行いません。 [07:00:02] 未実行の状態です。 [07:00:02] リンク取得は正常です。

ERROR: で始まる行が出た場合は Q&A タブを参照してください。

5
本番実行
▶
python3 fetch_update.py

同じフォルダに 医薬品供給状況_検索.html ができます。ダブルクリックすればブラウザで開きます。

コマンドの使い分け：

コマンド動作
fetch_update.py更新があるときだけ作り直す（通常はこれ）
--check確認のみ。ファイルは一切作らない
--force更新がなくても強制的に作り直す
6
毎日自動で動かす（任意）
▶

Mac / Linux — ターミナルで crontab -e と入力し、次の行を追加（毎朝7時）：

0 7 * * * cd /path/to/folder && /usr/bin/python3 fetch_update.py >> update.log 2>&1

パスはご自身のものに置き換えてください。

Windows — 「タスク スケジューラ」を開き：

  1. 「基本タスクの作成」→ 名前を入力 → 「毎日」→ 時刻を7:00に
  2. 「プログラムの開始」を選択
  3. プログラム欄：python
  4. 引数の追加欄：fetch_update.py
  5. 開始（オプション）欄：解凍したフォルダのパス

手順5の「開始（オプション）」が空だと失敗します。忘れやすい箇所です。

よくある質問

更新が無い日はどうなりますか

何もせず終了します。ページは前回のままです。ログには「変更なし」と出ます。

厚労省のサーバーに迷惑になりませんか

1日1回のアクセスなので問題ありません。ただし実行間隔を1日1回より短くしないでください。

元のExcelが更新される頻度は

不定期です。毎日チェックして、差分があったときだけ動く仕組みにしてあります。

ファイル名が同じまま中身だけ変わった場合は

検出できます。ファイル名ではなく中身のハッシュ値（SHA-256）で比較しているためです。

動かなくなりました

厚労省側のページ構成やExcelの様式が変わった可能性があります。ログに出る内容で原因が分かります。

ログ意味対処
Excelリンクが
見つかりません		リンクの形式が変わったfetch_update.py の find_xlsx() を修正
列数が想定と
異なります		Excelの様式が変わったbuild_html.py の列番号を確認
通信に失敗
しました		ネット接続または厚労省側の一時的障害時間をおいて再実行
検索ページの絞り込みはどう使いますか

チップは「状況」と「剤形」の2グループに分かれており、複数選択できます。

  • 同じグループ内は「または」…「限定出荷」＋「供給停止」＝どちらかに該当
  • 違うグループ同士は「かつ」…「限定出荷」＋「内用薬」＝限定出荷の内用薬

選択中の条件は検索窓の下に表示され、×で個別に、すべて解除で一括で外せます。もう一度チップを押しても解除できます。

薬効分類・製造販売業者の絞り込み、キーワード検索とも組み合わせられます。

両方の方法を同時に使えますか

使えますが、意味はありません。どちらか一方で十分です。

スマホだけで方法Aの設定はできますか

ファイルのアップロード（手順3）にPCがあった方が確実です。設定さえ終われば、以後の閲覧はスマホだけで完結します。
