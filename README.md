# 医療用医薬品供給状況 自動更新システム

厚生労働省のページを毎日自動で見に行き、Excelが更新されていれば
スマホ用の検索ページを作り直す仕組みです。

---

# ■ まず「どの方法にするか」を選んでください

方法は2つあります。**どちらか一方だけ**やれば動きます。

|  | 方法A：GitHub | 方法B：自分のパソコン |
|---|---|---|
| 費用 | 無料 | 無料 |
| PCの電源 | **切ってOK** | **つけっぱなしが必要** |
| スマホからの利用 | どこからでも見られる | そのPCの中でしか見られない |
| 必要なもの | メールアドレスだけ | Pythonのインストール |
| 難易度 | 手順は多いが画面に従うだけ | Pythonが入れば簡単 |

> **迷ったら方法Aです。**
> スマホで見るのが目的なら、方法Bはあまり意味がありません
> （PCの中にファイルができるだけで、スマホから見られないため）。

# ■ 方法A：GitHub で毎日自動更新する（推奨）

## これは何をするものか

GitHub という無料サービスに、この仕組みを置いておきます。
GitHubのコンピュータが毎朝7時に勝手に動いて、更新があればページを作り直します。
**あなたのパソコンは関係ありません。電源が切れていても動きます。**

できあがるもの：
`https://あなたの名前.github.io/リポジトリ名/` という**URL**
→ これをスマホのホーム画面に入れておけば、常に最新版が見られます。

## 必要なもの

- **メールアドレス**（GitHubの登録に使います）
- **パソコン**（設定作業のときだけ。以後は不要）
- Pythonのインストールは**不要です**

## 手順

### 1. GitHubにアカウントを作る

https://github.com/signup を開き、メールアドレスとパスワードを登録します。
無料プランで十分です。

### 2. 置き場所（リポジトリ）を作る

1. ログイン後、画面右上の **「+」** → **「New repository」** をクリック
2. **Repository name** に好きな名前を入力（例：`iyakuhin`）
3. **Public** を選択（Privateだと無料でのページ公開ができません）
4. 緑の **「Create repository」** ボタンをクリック

### 3. ファイルをアップロードする

1. 作成された画面に **「uploading an existing file」** というリンクがあるのでクリック
   （見当たらない場合は **Add file** → **Upload files**）
2. **ZIPを解凍した中身**を、フォルダごと画面にドラッグ＆ドロップします
   - 解凍してできたフォルダを開いて、**中のファイル全部**を選んでドラッグしてください
   - `.github` という名前のフォルダも必ず含めてください（これが自動実行の本体です）
3. 下の緑の **「Commit changes」** ボタンをクリック

> **注意：`.github` フォルダが見えない場合**
> Windowsは「表示」→「隠しファイル」にチェック、
> Macは `Command + Shift + .`（ピリオド）で表示されます。

### 4. 自動実行の許可を出す

1. 上部メニューの **「Settings」**（歯車マーク）をクリック
2. 左メニューの下の方にある **「Actions」** → **「General」** をクリック
3. 一番下までスクロールし、**「Workflow permissions」** の項目で
   **「Read and write permissions」** を選択
4. **「Save」** をクリック

### 5. ページ公開の設定をする

1. 同じく **「Settings」** の左メニューから **「Pages」** をクリック
2. **「Source」** のプルダウンを **「GitHub Actions」** に変更

### 6. 初回だけ手動で動かす

1. 上部メニューの **「Actions」** をクリック
2. 左に「医薬品供給状況の自動更新」があるのでクリック
3. 右側の **「Run workflow」** ボタン → もう一度 **「Run workflow」**
4. 1〜2分待つと、緑のチェックマーク ✅ が付きます

### 7. できたURLを確認する

**Settings** → **Pages** に戻ると、上部に
`Your site is live at https://...` とURLが表示されます。
スマホでそのURLを開き、ホーム画面に追加してください。

**以降は毎朝7時に自動で更新されます。何もする必要はありません。**

### うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| Actionsに赤い ❌ が付く | ❌をクリックするとエラー内容が読めます。多くは手順4の権限設定漏れです |
| Pagesにurlが出ない | 手順5をやり直し。手順6の実行が成功していないとURLは出ません |
| 「Run workflow」が無い | `.github` フォルダがアップロードされていません。手順3をやり直してください |

# ■ 方法B：自分のパソコンで動かす

PC内にHTMLファイルができるだけで、**スマホからは見られません。**
PCで使う場合や、動作確認をしたい場合向けです。

## 必要なもの

- **Python 3.8以上**（3.11以上を推奨）
- インターネット接続
- 定期実行するなら、その時刻にPCがついていること

## 1. Pythonが入っているか確認する

**Windows**：スタートメニューで「cmd」と検索し、コマンドプロンプトを開いて
**Mac**：「ターミナル」アプリを開いて

次を入力しEnter：
```
python3 --version
```

`Python 3.11.5` のようにバージョンが表示されればOKです。
`command not found` や「認識されていません」と出たら、
https://www.python.org/downloads/ からインストールしてください。

> **Windowsでのインストール時の注意**
> インストーラ最初の画面で **「Add Python to PATH」に必ずチェック**を入れてください。
> ここを忘れると上のコマンドが通りません。
> また、Windowsでは `python3` ではなく `python` の場合があります。

## 2. 必要なライブラリを入れる

```
pip install pandas openpyxl
```

（Windowsで通らない場合は `py -m pip install pandas openpyxl`）

## 3. フォルダへ移動する

ZIPを解凍した場所へ移動します。`cd` の後ろは**ご自身のパス**に置き換えてください。

```
cd /Users/yourname/Downloads/自動更新システム     ← Macの例
cd C:\Users\yourname\Downloads\自動更新システム   ← Windowsの例
```

> **簡単な方法**：`cd ` と入力した後（半角スペースまで）、
> フォルダをターミナル/コマンドプロンプトの窓にドラッグ＆ドロップすると
> パスが自動入力されます。

## 4. まず確認だけしてみる

```
python3 fetch_update.py --check
```

これは**ダウンロードもファイル作成もしません**。
厚労省ページを見に行けるかだけを確認する安全なコマンドです。

成功すると、こう表示されます：
```
[2026-07-23 07:00:01] 厚労省ページを確認中…
[2026-07-23 07:00:02] 掲載中: 医療用医薬品供給状況（令和８年７月22日現在）
[2026-07-23 07:00:02]   URL : https://www.mhlw.go.jp/content/10800000/260722iyakuhinkyoukyu.xlsx
[2026-07-23 07:00:02] --check のため、ダウンロードは行いません。
[2026-07-23 07:00:02]   未実行の状態です（state.json なし）。
[2026-07-23 07:00:02] リンク取得は正常です。
```
`ERROR:` で始まる行が出た場合は、下の「よくある質問」を参照してください。

## 5. 本番実行

```
python3 fetch_update.py
```

同じフォルダに `医薬品供給状況_検索.html` ができます。
ダブルクリックすればブラウザで開きます。

**コマンドの使い分け：**

| コマンド | 動作 |
|---|---|
| `python3 fetch_update.py` | 更新があるときだけ作り直す（通常はこれ） |
| `python3 fetch_update.py --check` | 確認のみ。ファイルは一切作らない |
| `python3 fetch_update.py --force` | 更新がなくても強制的に作り直す |

## 6. 毎日自動で動かす（任意）

**Mac / Linux** — ターミナルで `crontab -e` と入力し、次の行を追加
（毎朝7時に実行。パスはご自身のものに置き換えてください）：
```
0 7 * * * cd /Users/yourname/Downloads/自動更新システム && /usr/bin/python3 fetch_update.py >> update.log 2>&1
```

**Windows** — 「タスク スケジューラ」を開き：
1. 「基本タスクの作成」→ 名前を入力 → 「毎日」→ 時刻を7:00に
2. 「プログラムの開始」を選択
3. プログラム欄：`python`
4. 引数の追加欄：`fetch_update.py`
5. **開始（オプション）欄：解凍したフォルダのパス**（ここが空だと失敗します）

# ■ よくある質問

**Q. 更新が無い日はどうなりますか**
何もせず終了します。ページは前回のままです。ログには「変更なし」と出ます。

**Q. 厚労省のサーバーに迷惑になりませんか**
1日1回のアクセスなので問題ありません。ただし**実行間隔を1日1回より短くしないでください。**

**Q. 元のExcelが更新される頻度は**
不定期です。毎日チェックして差分があったときだけ動く仕組みにしてあります。

**Q. 動かなくなりました**
厚労省側のページ構成やExcelの様式が変わった可能性があります。
ログに出る内容で原因が分かります：

| ログ | 意味 | 対処 |
|---|---|---|
| `Excelリンクが見つかりません` | リンクの形式が変わった | `fetch_update.py` の `find_xlsx()` を修正 |
| `列数が想定と異なります` | Excelの様式が変わった | `build_html.py` の列番号を確認 |
| `通信に失敗しました` | ネット接続・厚労省側の一時的障害 | 時間をおいて再実行 |

# ■ ファイルの説明

| ファイル | 役割 | 触る必要 |
|---|---|---|
| `fetch_update.py` | 巡回して差分を判定する本体 | なし |
| `build_html.py` | Excelを検索HTMLに変換する | なし |
| `template_head.html` | 見た目（デザイン） | 見た目を変えたいときだけ |
| `template_tail.html` | 検索の動作 | 動作を変えたいときだけ |
| `.github/workflows/update.yml` | 毎日7時の自動実行設定 | 時刻を変えたいときだけ |
| `state.json` | 前回のファイル情報（自動生成） | なし |

**実行時刻を変えたい場合**：`.github/workflows/update.yml` の
`- cron: '0 22 * * *'` を編集します。**UTC表記**なので日本時間から9引いてください
（例：日本時間12時 → `0 3 * * *`）。
